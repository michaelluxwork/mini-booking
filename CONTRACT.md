# Mini Booking — контракт реализации

Сфера: одна переговорная, 09–18 каждый день, 7дней заполнения, API и страница. Подтверждённый план read-only архитектурой16.11.
SQLite: timestamps начала/конца — Unix seconds UTC; starts_at UNIQUE (одна комната), bookings.slot_id UNIQUE + FK. Отмена удаляет активную запись. Миграция rollback сначалаbookings,затемslots; перед откатом копироватьSQLite, не удалять её.
POST:JSON,валидацияLaravel422,затем IMMEDIATE-транзакция. Время проверяется после захвата writerlock; start<=now→409. INSERTпод защитойUNIQUE; конкретный UniqueConstraintViolationException→409. SQLitebusy_timeout5000,исчерпание→503,не409. Серверная timezone=APP_TIMEZONE.
GET: data[{id,starts_at,ends_at,status,booking_id}],timezone,server_now. ISO8601со смещением; pastимеет приоритет. Имя/emailне возвращаются. DELETEидемпотентный204.

Frontend:Vue3scriptsetup,NaiveUI;дата/время вtimezoneAPI,состояния изAPI;локальный таймер синхронизировансserver_now. Формыrequired/email,422по полям,409собновлениемсписка,сетеваяошибка/повтор,блокировкадействийна запросе,отмена с подтверждением. Данныеформы не сохраняютсявбраузере.
