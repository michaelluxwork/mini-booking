# Изолированная проверка конкурентности Mini Booking

Вердикт: **PASS для проверенного состояния исходников**. Это не финальная приёмка всего приложения; независимые security/QA-гейты сохраняются.

Команда из корня проекта:

```text
rtk proxy python -X utf8 quality/race-check.py
```

Сценарий использует переносной PHP `.tools/php/php.exe`, запускает миграции на новом SQLite-файле внутри `.runtime/race-*/` и создаёт один синтетический будущий слот. Рабочая `backend/database/database.sqlite` не используется для запросов сценария.

Каждый раунд запускает **четыре независимых PHP-процесса с отдельными подключениями SQLite**. Они загружают Laravel, доходят до файлового барьера, после общего сигнала одновременно отправляют POST через настоящий Laravel HTTP kernel, маршрутизацию, валидацию, контроллер и БД. Новый сетевой сервер не открывается.

| Проверка | Результат |
| --- | --- |
| Три раунда конкурентного POST | В каждом:201,409,409,409 |
| Активных записей после каждого раунда | Ровно1 |
| Чтение из нового PHP-процесса | Видит bookedиIDсохранённойброни |
| Отмена из нового процесса |204 |
| Повторная отмена |204 |
| Чтение после отмены из нового процесса |available |
| Следующий раунд на том же слоте |Снова ровнооднабронь |
| SHA256рабочейdatabase.sqlite до/после |Совпадает |
| SHA256проверяемых исходников до/после |Совпадает |

Точные timestampsUTC, команды, исходные SHA256и результаты находятся в `race-result.json`. Отдельного Gitcommitна момент проверки нет; результат привязан к manifestSHA256, не к незаявленной ревизии. Если родитель изменит эти файлы, сценарий необходимо повторить на финальном кандидате.

Границы: это проверка гонки бронирования и чтения/отмены после перезапуска процесса, не долговременная нагрузка, сетевой throughput, потеря питания или проверка файловой системы при отказе. Последовательные PHPUnit-тесты не подменяют этот сценарий. Используются только синтетические name/emailсдоменомexample.test; отчёт не содержит этих полей. Изолированная база оставлена в игнорируемой `.runtime/` для воспроизводимости и не является артефактом сдачи.
