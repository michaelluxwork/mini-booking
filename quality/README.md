Разработка, запуск проверок и подготовка этого описания выполнялись с помощью ИИ-инструментов. Это результаты локальных автоматизированных и браузерных проверок, а не независимый человеческий аудит или сертификация безопасности.

## Проверенное состояние

Проверки приложения выполнены 16 ноября 2026 года. Основная проверенная ревизия: `1abccce990101317f7f3237bfc7e36d8dbe41aa9`. Последующие изменения документации не изменяют код приложения. Результаты относятся к указанной ревизии и окружению, а не гарантируют отсутствие ошибок при любых условиях.

Тесты приложения находятся в `backend/tests/`. Команды обычного запуска и тестирования приведены в [основном README](../README.md).

Дополнительные сценарии из корня проекта:

```sh
python quality/race-check.py
python quality/clean-check.py
```

Эти два сценария рассчитаны на подготовленную Windows-машину с переносным PHP в `.tools/php/php.exe`. Проверка чистого клона использует локально доступные инструменты, поэтому не заменяет проверку установки PHP и Composer на другом компьютере.

- [race-check.py](race-check.py) и [kernel-worker.php](kernel-worker.php) запускают конкурентные запросы через Laravel HTTP kernel с отдельными подключениями SQLite и общей точкой старта. Результаты и контрольные суммы исходников: [race-result.json](race-result.json).
- [clean-check.py](clean-check.py) проверяет установку и запуск из отдельного локального клона. Результат: [clean-result.json](clean-result.json).

Сценарий конкурентности использует отдельную базу в игнорируемой папке `.runtime/`; рабочая база для запросов не используется. Проверено сохранение её контрольной суммы. Это проверка конкурентного создания, чтения и отмены брони, а не длительное нагрузочное испытание или имитация отказа диска.

## Браузерные проверки

На локальном демо проверены:

- выбор даты, отображение времени и трёх статусов;
- создание и отмена брони с обновлением без перезагрузки страницы;
- ошибки полей при 422 и конфликт 409 после бронирования другим клиентом;
- блокировка формы во время запроса;
- ошибка загрузки, повторная загрузка и восстановление после сбоя;
- работа клавиатуры, подписи полей и закрытие окна через Escape;
- адаптация под ширину 390 пикселей, раскрытый выбор даты и размещение модального окна.

Использовались вымышленные данные. Реальный телефон не проверялся: мобильный сценарий проверен в эмуляции браузера. Автоматизированный браузерный тест в репозиторий не добавлен; этот раздел описывает выполненные проверки, а не отдельный воспроизводимый E2E-набор.

## Ограничения

Приложение предназначено для локального демонстрационного запуска. Проверялись ответы на недопустимые Host/Origin, слишком большое тело запроса, POST без JSON и отсутствие отладочного стека в API. Эти проверки не являются полным аудитом безопасности. Авторизации нет по условиям задания: отмена доступна по известному номеру брони.

Внутренние рабочие отчёты перенесены в личные локальные материалы; сценарии и результаты сохранены. Предыдущие версии документов остаются в истории Git.
