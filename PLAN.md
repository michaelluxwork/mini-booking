# Mini Booking

Отдельный проект тестового задания: бронирование одной переговорной.

## Статус

Окружение подготовлено отдельно. Реализация и приёмка: 16.11.2026, 18:20:15–18:47:11 МСК (26 мин 56 с календарного времени). Функции по ТЗ реализованы; независимые security/QA — PASS для локального демо. Контрольная граница двухчасового интервала — 20:20:15 МСК. Публикация, отправка и самостоятельная защита не выполнены.
Дедлайн: 17 ноября 2026, 17:00 МСК — по согласованному в чате сроку.
Оригинал задания остаётся в исходной папке Downloads/Telegram Desktop; здесь только технический план, без копии переписки и клиентских данных.

## Согласованное направление

Laravel (PHP 8.2+, Laravel 11+), Vue 3 Composition API/script setup, SQLite, готовая библиотека UI-компонентов.
Выбраны PHP8.4.27, Composer2.11.2, Laravel13.42.0, Vue3.5.45, Vite8.3.8, NaiveUI2.45.3.

## Обязательный результат

- Миграции слотов и бронирований; стратегия отмен и гарантия одного активного бронирования на слот на уровне БД.
- Идемпотентный Seeder: сегодня и ещё 6 календарных дней, ежедневно 9 часовых слотов с 09:00 до 18:00 в часовом поясе Laravel; старые данные сохраняются.
- GET /api/slots: сортировка, время со смещением, статусы и ID активного бронирования; без имени/email.
- POST /api/bookings: slot_id/customer_name/customer_email; 201, полевые ошибки422, конфликт409 для занятого/прошедшего; корректность одновременных запросов.
- DELETE /api/bookings/{id}: 204, будущий слот снова доступен; повторная отмена204или404.
- Адаптивная страница: фильтр даты, статусы, форма, подтверждение отмены, загрузка, блокировка повторных действий, ошибки422/409/сети и повтор запроса; обновление без перезагрузки; отдельный API-модуль.
- Два обязательных теста: успешное бронирование будущего слота; повторное бронирование409без второй активной записи.
- README: зависимости, окружение, запуск, миграции/Seeder/тесты, уникальность, часовой пояс, незавершённое.
- Репозиторий для сдачи. Публикация отдельно, после проверки содержимого.
